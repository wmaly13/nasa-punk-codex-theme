NASA 朋克主题 · Windows x64 测试包 0.7.1

安装一次：
1. 完整解压到普通文件夹。不需要放在系统根目录，不要在 ZIP 内运行。
2. 手动完全退出当前 ChatGPT/Codex，包括后台实例。
3. 双击“安装主题.exe”。程序复制文件、导入主题，自动创建桌面和开始菜单入口。
4. 安装完成后，使用桌面“ChatGPT · NASA 朋克”打开客户端。

日常使用：
从“ChatGPT · NASA 朋克”启动。它只启动与加载，不重复安装。
可以在开始菜单搜索“ChatGPT · NASA 朋克”，右键将该入口固定到任务栏。
重启电脑后也用这个新图标；原版 ChatGPT 图标会打开官方外观。
安装成功后可删除下载 ZIP 和解压目录，桌面入口指向固定的用户目录。
安装程序不会自动打开或关闭客户端。已有经验证的 NASA 主题会话时，切回已有窗口，不重复开客户端；只有原生会话或无法验证时才提示手动退出。

卸载：
完全退出客户端后，运行“卸载主题.exe”或开始菜单“卸载 NASA 朋克主题”。
关闭完成窗口后，清理本主题程序与备份。已有运行器、其他主题及用户改动保留。
只有本包首次安装且不被其他主题使用的运行器会移除。
缺失恢复备份时会停止卸载并保留记录，不覆盖其他配置项。

旧版错误修复：
0.6.1 安装/卸载调用了不存在的上游函数，会留下未完成记录。
请使用 0.7 修复，不要手动删除旧备份。
0.7 分离安装与日常启动，在创建、校验桌面入口后才报告安装完成。

验证边界：
包含隔离 Windows PowerShell 5.1 回归；真实客户端冷启动、电脑重启及另一台干净电脑验收尚待完成。
图片切换流畅度尚未完成受控复测。固定使用 Codex Dream Skin 1.5.20。
只支持受支持的 Windows x64 OpenAI.Codex Store 应用，并不支持所有 ChatGPT 客户端。
程序未做代码签名。概念效果图的全部后续面板改造尚未完成。
