# NASA 朋克浅色主题

自己折腾的 NASA 朋克浅色皮肤，给 Windows 版 Codex / ChatGPT 换个样子。还没打磨好，先放上来。

当前是 **v0.7.3-beta 预发布实验版**，面向 **Windows x64 OpenAI.Codex Store 桌面客户端**，不代表支持所有 ChatGPT 安装版或其他系统，也不是 NASA 或 OpenAI 官方产品。当前依赖 Codex Dream Skin **1.5.20**，使用时需要额外运行组件和专用主题启动入口，可能需要重新登录。

## 使用

1. 从 [Releases](https://github.com/wmaly13/nasa-punk-codex-theme/releases) 下载 `NASA-Punk-Windows-v0.7.3-beta.zip` 并完整解压。
2. 手动完全退出客户端，运行 `安装主题.exe`。
3. 安装后从桌面上的 **ChatGPT · NASA 朋克** 入口启动。
4. 卸载前手动完全退出客户端，再运行 `卸载主题.exe`。

## 目前的限制

仍需使用 NASA 专用启动入口；Windows 通知可能另外打开原生窗口。安装、冷启动、重启电脑和干净电脑的完整流程尚未全部验收；图片开关的流畅度也还没复测。安装程序未签名，Windows 可能显示未知发布者提示。
